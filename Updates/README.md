# Updates — plain-language log for the owner

Every Claude session writes a short summary here after doing meaningful work.
**Summaries only — no source code goes in this folder.**

Each file uses this simple format:

```
# <Short title> — <date>

## What I did
- Plain-language bullet. What changed for you, not how.
- Keep it short and skimmable.

## What I recommend next
- Clear next step or option.
- Note anything that needs YOU to act (e.g. accounts, keys, decisions).
```

- Files are named `YYYY-MM-DD-short-title.md`.
- Newest work = newest date. Skim top to bottom of any file in seconds.
